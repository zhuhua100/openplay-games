关于 OpenPlay Games

一个开源 HTML5 小游戏发现平台

🌐 网站介绍

OpenPlay Games 是一个专注于收录和展示 GitHub 开源 HTML5 游戏的平台。我们的使命是让更多人发现和享受优质的开源游戏作品，同时也为开源开发者提供展示作品的窗口。

本站收录的所有游戏均来自 GitHub 开源社区，遵循相应的开源协议（MIT、BSD、Apache-2.0 等）。我们坚持只收录有明确开源许可证的项目，尊重每一位开发者的劳动成果。

无论你是想找一款经典游戏放松心情，还是想学习 HTML5 游戏开发的源码，这里都能满足你的需求。

📜 开源声明

OpenPlay Games 本身也是一个开源项目。本站的源代码托管在 GitHub 上，欢迎任何人查看、学习和贡献。

本站收录的每个游戏页面都明确标注了：

  • 原作者信息（Author）
  • 开源协议（License）
  • 原项目 GitHub 地址

所有游戏的版权归原作者所有。本站仅作收录和展示，不主张任何游戏内容的版权。

⚖️ DMCA 版权声明

我们尊重知识产权。如果您是某个游戏的原作者，认为本站收录您的作品侵犯了您的权益，请通过以下方式联系我们。

我们承诺在收到有效的版权投诉后，将在 48 小时内移除相关内容。

联系我们时请提供：

  • 您的姓名和联系方式
  • 被侵权作品的详细描述
  • 该作品在本站的具体页面链接
  • 您是版权所有者或授权代表的声明

🔒 隐私政策

本站非常重视您的隐私。我们承诺：

  • 本站不收集用户的个人信息
  • 本站不使用追踪脚本或分析工具
  • 本站不设置 Cookie（除非未来接入广告后由广告平台设置）
  • 本站所有游戏均在本地运行，不会上传任何用户数据

如果未来接入 Google AdSense 广告，Google 可能会使用 Cookie 来提供个性化广告。届时我们会更新本政策。
